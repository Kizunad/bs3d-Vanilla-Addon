# 交互与支持范围

右键原版工作站或容器后，操作区保持原版布局。左侧显示可拖动旋转的玩家，右侧用于打开随身背包的三维内景。背景透出当前世界，不改变第一人称视角；附属场景启用时隐藏全部原版 HUD。

## 拖放

- 双手和盔甲部位可以取出、放入物品。服务器通过原版玩家菜单执行点击，保留装备部位和绑定诅咒规则。
- 把模型部位或背包内景物品拖向原版槽位。松开时提交一次完整 MOVE，服务端在同一调用内交换背包并执行一次原版点击，任一步失败均恢复来源。没有预定落点等待回执的中间态。
- 原版槽位可直接拖向人物部位、容器模型或内景格子，已有光标栈也可作为来源。空白处可旋转场景，人物区也可按住右键拖动旋转，内景滚轮缩放；R/T 使用 BS3D 已绑定的旋转按键，Shift 反向。
- 点击身上的背包打开内景；右侧同时展示一个内景，再点其他背包可切换。标题只提供最小化和关闭按钮；范围条复用 BS3D 的双端格层筛选。信息按钮按需显示说明。
- 物品简介仍走原版 tooltip 与 BS3D 描述注册。
- BS3D 装备拖到人物任意部位即可穿戴，包含容器、腰带及 Gear；原版甲和普通物品保留原有部位与收纳规则。
- 右键单击人物打开“脱掉 XXX”列表，列出全部挂载根装备。滚轮翻页，点击条目后经服务器整件取回原版主背包；空间不足保留原装备与内容。右拖仍旋转人物。列表开启时 ESC、右键或点击外部先关闭列表。

Shift 点击原版槽位或模型双手物品，按腰挂优先寻找有空位的随身容器；Shift 点击内景物品，使用原版 insertItem 合并进入主背包和快捷栏。放不下原位不动。

普通物品拖到容器模型自动放置，开盖与合盖同样有效，保持朝向并使用完整容量；可穿戴装备拖到身上容器优先穿戴，收纳时拖到内景具体格位。携物悬停显示可落颜色及目标。服务端校验菜单身份、来源与落点指纹、距离和版本，完成后只播放一次材质声；无计时、进度条或行走锁。拒绝原因显示在状态区。

普通原版点击仍保留原版光标语义；附属拖放不交换目标中不同物品，也不进行部分插入。已有光标栈失败时仍在光标，关闭页面由原版归还。

## 原版页面

| 分类 | 支持 |
| --- | --- |
| 玩家 | E 键玩家背包页、创造模式全部页签（同一三维场景；Pocket 附属布局另行提供） |
| 制作与加工 | 工作台、铁砧、锻造台、砂轮、切石机、织布机、制图台 |
| 燃料与材料 | 熔炉、高炉、烟熏炉、酿造台、附魔台、信标 |
| 存储 | 1–6 行原版通用容器、箱子及双箱、陷阱箱、末影箱、木桶、潜影盒 |
| 小容器 | 漏斗、发射器、投掷器 |

只按显式原版 `MenuType` 适配。村民交易、马匹库存、讲台及第三方自定义菜单未适配；不会强行覆盖这些页面。创造模式的物品栏、搜索页与类别页均可使用人物装备目标。

创造模式服务器侧菜单是玩家菜单，页面真实槽映射后沿用同一事务。创造类别页直接拿起 Gear 或 BS3D 装备拖向人物时，先经原版创造权限写入一个可见空库存槽，再引用该真实槽提交穿戴；不要求玩家手动放槽。库存已满时保留光标，穿戴冲突时物品留在刚取得的库存槽。原版盔甲部位、删除格与 Shift 删除仍使用原版规则。非装备物品收纳到内景前仍需先放进真实槽。

原版配方书展开时，场景临时让出空间并恢复原版显示，关闭配方书后恢复。两侧任一区域不足 96 GUI 像素或场景高度不足 160 GUI 像素也退回原版页面，可降低 GUI 缩放。铁砧文字框保持原版输入；仅在鼠标位于内景且光标携物时消费 R/T。

创造授权包和穿戴意图使用同一连接按序处理；业务协议只传真实槽号与指纹，不传客户端库存数据。

场景首次打开时申请附近地面背包的访问租约，沿用 BS3D 的距离、遮挡和独占规则。地面模型显示在人物旁，可直接拖入，也可点击打开内景取回；关闭页面释放租约。Shift 自动存入仍只选择随身容器。右侧内景尚未改为多个同时展开的窗口。
