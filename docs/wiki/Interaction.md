# 交互与支持范围

右键原版工作站或容器后，操作区保持原版布局。左侧显示可拖动旋转的玩家，右侧用于打开随身背包的三维内景。背景透出当前世界，不改变第一人称视角；附属场景启用时隐藏全部原版 HUD。

## 拖放

- 双手和盔甲部位可以取出、放入物品。服务器通过原版玩家菜单执行点击，保留装备部位和绑定诅咒规则。
- 把模型部位或背包内景物品拖向原版槽位。背包取出需要服务端计时，鼠标提前松开时保留落点，成功回执后才交给原版槽位；页面已经关闭则丢弃落点。
- 原版物品先按正常点击或拖动拿到光标，再拖向人物部位或背包内景格子。空白处可旋转场景，内景滚轮缩放；R/T 使用 BS3D 已绑定的旋转按键，Shift 反向。
- 点击身上的背包打开内景；右侧同时展示一个内景，再点其他背包可切换。标题只提供最小化和关闭按钮；范围条复用 BS3D 的双端格层筛选。信息按钮按需显示说明。
- 物品简介仍走原版 tooltip 与 BS3D 描述注册。

背包与光标的转移使用 BS3D 服务端材质时长，期间锁定行走和原版槽位点击。ESC、背包关闭快捷键、换页、断线、死亡、超出交互距离或来源变化都会终止未提交操作。完成时播放材质接触音效。

原版光标语义保持不变：拿在光标中的物品已经离开原槽位，关闭页面由原版归还或掉落。合并、交换及剩余数量以原版左键语义为准；无法插入时物品保留在光标。背包中的内容不会由客户端自行扣除。

## 原版页面

| 分类 | 支持 |
| --- | --- |
| 制作与加工 | 工作台、铁砧、锻造台、砂轮、切石机、织布机、制图台 |
| 燃料与材料 | 熔炉、高炉、烟熏炉、酿造台、附魔台、信标 |
| 存储 | 1–6 行原版通用容器、箱子及双箱、陷阱箱、末影箱、木桶、潜影盒 |
| 小容器 | 漏斗、发射器、投掷器 |

只按显式原版 `ScreenHandlerType` 适配。村民交易、马匹库存、讲台、创造物品栏及第三方自定义菜单未适配；不会强行覆盖这些页面。

原版配方书展开时，场景临时让出空间并恢复原版显示，关闭配方书后恢复。两侧任一区域不足 96 GUI 像素或场景高度不足 160 GUI 像素也退回原版页面，可降低 GUI 缩放。铁砧文字框保持原版输入；仅在鼠标位于内景且光标携物时消费 R/T。

当前内景限随身可访问的容器；地面背包继续使用 BS3D 独立页面与访问租约。右侧内景尚未改为多个同时展开的窗口。
